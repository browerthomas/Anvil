# speckit-gold — proposal

> Lift the five ideas from GitHub's spec-kit (96k★) that anvil is genuinely missing, without adopting speckit's plan/spec/tasks separation or its tech-stack-segregation rule (both wrong fits for anvil's engineer-audience grind loop).

**Status:** draft
**Author:** tb
**Date:** 2026-05-12
**Plan ID:** speckit-gold
**Layout:** folder

---

## Goal

Five additive features land in anvil that close the real gaps between anvil and spec-kit: a **constitution** artifact that every dispatched agent reads, a **template override hierarchy** so projects can customise without forking, **per-slice checklists** threaded through `/pre-merge-gate`, a **/clarify** skill that separates interrogation from spec-writing, and an **/analyze-plan** lock-time consistency gate. Each is independently shippable; together they close the front-half methodology gap that spec-kit owns.

---

## Why now

- Spec-kit just crossed 96k★ on the same core loop anvil targets; the operator has flagged its constitution + template-override + checklist + clarify + analyze ideas as load-bearing upstream of anvil's strongest surface (the execution loop).
- Anvil's strength is the back half (`/grind`, `/codex-review`, `/dual-review`, `/pre-merge-gate`, `/auto-merge`, event log, plan-health). Front half (intent → locked plan) is comparatively thin. These five additions close that gap without churning the back half.
- Templates already live under `templates/` but are read from a fixed path with no override layer. Adopting projects can't customise without forking the repo. This bites OSS reach.
- Dispatched agents currently rediscover project rules per-slice from grep-friendly but unread `.anvil/*.txt` files. A unified constitution.md pinned into every brief closes that leak.

---

## Scope

### In scope

- New artifact: `.anvil/constitution.md` (project-local, generated by `config-bootstrap`, prepended into every `dispatch-slice` brief).
- New helper: `av_resolve_template` in `shared/lib.sh` with a 3-level resolver — project overrides → user presets → core defaults.
- New plan field: `checklist:` per slice in `tasks.md`, consumed by `/pre-merge-gate` at merge time.
- New skill: `/clarify` — interactive Q&A that writes a transcript file consumed by `/spec`.
- New skill: `/analyze-plan` — lock-time consistency gate that greps factual claims in a locked plan against current code.
- Updates to existing skills: `dispatch-slice`, `config-bootstrap`, `spec`, `pre-merge-gate`, `grind`.
- Smoke tests under `tests/` for each new surface.
- Documentation in `docs/` + CHANGELOG entry + ROADMAP tick.

### Out of scope

- Splitting anvil's plan into separate spec/plan/tasks artifacts (speckit's 3-file split). Anvil's audience is engineers; one plan document is fit-for-purpose.
- "No tech in spec" rule from speckit — wrong audience for anvil.
- Multi-agent emit (writing the same prompts into `.codex/`, `.gemini/`, etc.). Strategic but not urgent; this plan stays Claude-Code-shaped.
- A constitution-version mechanism (constitution.md format version field). Defer until a second incompatible format is needed.
- `/speckit.analyze`-style cross-artifact consistency between proposal.md and tasks.md. Out of scope for this plan; the `/analyze-plan` skill here only checks claims-vs-code.

## Success criteria

- [ ] `.anvil/constitution.md` example file exists; populated by `config-bootstrap` on a fresh project; prepended to `dispatch-slice` agent brief; absent state is no-op.
- [ ] `av_resolve_template` resolves a project-local override over a core default; smoke-tested.
- [ ] A locked plan can carry per-slice `checklist:` items that `/pre-merge-gate` evaluates; failing item blocks merge; passing all items unblocks.
- [ ] `/clarify "intent"` writes a transcript file under `docs/plans/.clarify/`; `/spec --clarify-file <path>` consumes it without re-asking the same questions.
- [ ] `/analyze-plan <plan-path>` flags a deliberately stale file path in a plan; passes a plan whose claims match current code.
- [ ] All five surfaces have at least one smoke test in `tests/` and an entry in CHANGELOG.md.
- [ ] ROADMAP.md ticks the speckit-gold line.
