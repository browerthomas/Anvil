The friction it removes

Same workflow. Less hand-cranking.

Manually

600-word agent brief, hand-typed × 15 dispatches
6 manual checks (rebase, tsc, tests, fitness, grep, CI) × 12 PRs = 72 ops
5-step merge dance per PR (footguns at every step)
After each multi-critic: hand-write rollup issue, hand-brief fix-up agent
Accumulating worktrees + stale branches + cloud-sync-evicted node_modules
End-of-sprint summary: improvise from git log

With anvil

3-line invocation per slice — /dispatch-slice emits the full brief
1 invocation per PR — /pre-merge-gate returns one verdict
1 call — /auto-merge, footguns handled
1 call — /findings-rollup files the issue + dispatches the fix-up agent
1 call — /sweep-worktrees
1 call — /recap drops a visual HTML page

Three phases

Lay it. Strike it. Stamp it.

Each phase is one composable skill. Each composes the layer below. Adopt incrementally — they work standalone, and they work together.

/spec

Plan

/grind

/recap

The toolkit

Sixteen skills. One toolbox.

You won't invoke all 16. The orchestrator (/grind) composes most of them; you call the others directly when you need one piece.

Show all 16 skills
/spec

Capture work as a structured plan (interactive probe). Supports flat or OpenSpec-style folder layout, validates before /grind can execute.

/grind

Drive a plan end-to-end. Topo-sorts slices, dispatches in parallel where safe, reviews per PR, gates each merge. Pauses only at structured ASK verbs you defined; defers + continues siblings on failure. Replayable from the append-only event log.

/dispatch-slice

Fire an agent against one slice with the full prompt template (worktree, deps, constraints, commit format, return shape). Three-line invocation in place of 600-word briefs.

/pre-merge-gate

Verify a PR is mergeable: rebase + tsc + tests + fitness ratchets + grep for forbidden patterns + GH check status. One verdict. Also ships as an MCP server (@anvil/gate-mcp) so Cursor / Windsurf / ChatGPT desktop can call the same gate.

/auto-merge

Squash + delete branch + wipe worktree + clear stale locks + sync main. One call replaces five manual operations and the cloud-sync / stale-lock / branch-busy footguns.

/post-merge-debrief

After a one-off merge outside /grind: verify-merge → sweep-worktree → mark merged in event log → pull main → dispatch next slice.

/self-review

Adversarial diff review via an Opus sub-agent. --multi-critic runs four parallel critics (correctness / security / test-coverage / architecture) plus a synthesizer. Codex fallback.

/findings-rollup

Translate a multi-critic review into action: file P2/P3 as a rollup issue with checkboxes + dispatch a fix-up agent for the P0/P1 list. One invocation closes the 5-step manual sequence.

/refine-plan

Mid-grind plan correction. Edit plan files in-place, write a plan-revised event to the log, comment on any in-flight PRs whose contract just moved.

/config-bootstrap

Derive .anvil/ configs (forbidden patterns, dispatch defaults, known flakes) from your project's existing context docs (CLAUDE.md / AGENTS.md / post-mortems). Companion to bin/init-anvil-config.sh.

/issue-to-spec

Verify a GitHub issue body's factual claims against the codebase before locking a plan. Catches "issue body is wrong" errors at lock-time.

/sweep-worktrees

Bulk-clean stale worktrees + branches. Handles cloud-sync-evicted node_modules, stale git locks, force-deletes by PR-merge status.

/recap

Visual HTML session report — PRs, tests, lessons, loose ends, plus a Decisions strip surfaced from operator ASK records. Dropped into ~/.claude/showme/.

/learn

Forge a memory

Append-only per-project learnings log at .anvil/learnings.jsonl. Subcommands add, search, prune, summary, export. Skills auto-emit on discovery so chronic flakes stop being rediscovered every sprint.

Quickstart

From clone to first strike.

Pick the tier you chose above. Each is a complete onboarding path; you can level up later by re-running the next tier's bootstrap.

Just run this

one-liner install
$ git clone https://github.com/browerthomas/Anvil.git ~/anvil && ~/anvil/bin/install.sh
tier 1 — single skill
# Clone + install. Symlink-mode means edits to skills are live immediately.
$ git clone https://github.com/browerthomas/Anvil.git ~/anvil
$ ~/anvil/bin/preflight.sh # verifies gh + git + node + jq
$ ~/anvil/bin/install.sh
installed 16 skills → ~/.claude/skills/

# That's it. In Claude Code, run any one skill standalone:
claude> /sweep-worktrees # bulk-clean stale branches + worktrees
claude> /self-review # adversarial review of uncommitted diff
claude> /recap # visual HTML summary of last sprint
tier 2 — per-PR inner loop
# Tier 1 install steps (clone + preflight + install.sh) plus:
$ cd /path/to/your/project
$ ~/anvil/bin/init-anvil-config.sh
✓ wrote .anvil/forbidden-patterns.txt
✓ wrote .anvil/pre-merge-gate.config.json
✓ wrote .anvil/dispatch-defaults.txt + known-flakes.txt

# Optional: have the AI populate the .anvil/ configs from your project's docs.
claude> /config-bootstrap # derives rules from CLAUDE.md / AGENTS.md / post-mortems

# Now drive ONE PR through the inner loop:
claude> /dispatch-slice issue-1234 --scope "..."
claude> /pre-merge-gate <PR> # rebase + tsc + tests + fitness + grep
claude> /auto-merge <PR> # squash + cleanup + sync
tier 3 — end-to-end orchestration
# Tier 1 + 2 install + bootstrap, plus:

# 1. Capture intent as a structured plan (interactive probe).
claude> /spec "extract logging into a typed boundary"
→ docs/plans/2026-05-12-logger-boundary/{proposal,design,tasks,specs/}
validated: 7 slices · 23 acceptance criteria · 2 ASK points

# 2. Drive end-to-end. Pauses ONLY at decision points you defined.
claude> /grind docs/plans/2026-05-12-logger-boundary/
S1 dispatch → review → gate → merge ✓
S2 dispatch → review (BLOCK, fix-up agent) → gate → merge ✓
S3 ASK: "wire log-level env now or post-merge?" [approve|edit|reject|respond]
... 7/7 slices merged, 2 P2 follow-ups filed, 0 deferred

# 3. Stamp the work.
claude> /recap # visual HTML report
claude> /sweep-worktrees # bulk-clean per-slice worktrees
