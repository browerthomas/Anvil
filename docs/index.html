Three phases

Lay it. Strike it. Stamp it.

Each phase is a Claude Code skill. Each composes the layer below. Adopt incrementally — they work standalone, and they work together.

/spec

Lay the blueprint

Plan

Capture intent. Probe for ambiguity until the slice manifest is unambiguous. Lock the plan, mark operator decision points, ship it to the orchestrator.

/grind

Run the forge

Forge

Heat the plan. Strike per slice. Agents in parallel worktrees, adversarial review, pre-merge gate, auto-merge on green. Pauses only at decision points you defined.

/recap

Stamp the work

Recap

A scannable artifact you can share, archive, or fold into the next plan. PRs shipped, tests added, lessons learned, loose ends.

The toolkit

Eight skills. One toolbox.

Each stands alone. Together they're a framework. Markdown files in ~/.claude/skills/ — no compilation, no platform.

/spec spec'd

Lay the blueprint

Interactive plan capture. Probes for detail using the template, runs adversarial validation, outputs structured plan markdown.

/grind spec'd

Run the forge

End-to-end orchestrator. Reads a plan, dispatches in dep order, gates merges, files follow-ups, recaps. The conductor.

/dispatch-slice spec'd

Strike a billet

Codifies the agent prompt template — worktree, deps, commit format, return shape. Three-line invocation in place of 600-word briefs.

/pre-merge-gate spec'd

Inspect the seam

Combinator: rebase + tsc + vitest + fitness ratchets + grep-for-forbidden-patterns. One verdict, six manual checks gone.

/auto-merge spec'd

Quench and ship

When CI green: squash-merge + delete branch + wipe worktree + sync main. One call replaces five manual operations.

/self-review live

Test the temper

Adversarial diff review via Opus sub-agent. Codex-fallback when subscription is rate-limited. Structured P0/P1/P2/P3 findings.

/sweep-worktrees live

Reset the workshop

Bulk-clean stale worktrees + branches. Handles iCloud-evicted node_modules, stale git locks, force-deletes by PR-merge status.

/recap live

Stamp the work

Visual HTML session report — PRs, tests, lessons, loose ends. Pairs with session memory for durable + readable record.

Get started

Heat it. Strike it.

Five minutes from clone to first strike. Symlink-mode means edits to skills are live immediately.

~/Desktop/anvil
# 1. Heat the forge — verify your environment
$ ~/Desktop/anvil/bin/preflight.sh
✓ git, gh, node, jq found
✓ ~/.claude/skills/ writable
✓ find -delete works
preflight clean — ready to install

# 2. Stoke it — install the skills
$ ~/Desktop/anvil/bin/install.sh
+ sweep-worktrees
+ self-review
+ recap
+ dispatch-slice
+ pre-merge-gate
+ auto-merge
+ spec
+ grind
installed 8 skills

# 3. Strike — capture a plan, then run it
claude> /spec "what you want built"
claude> /grind docs/plans/<slug>.md

# 4. Stamp — recap when the dust settles
claude> /recap
